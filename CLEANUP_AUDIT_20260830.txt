V90 What's New / structure audit — 2026-08-30

Root cause found:
1) whatsnew.html loads assets/whatsnew-cms.js and assets/whatsnew.css.
2) A second, newer pair (whatsnew-cms.js / whatsnew.css) existed in the repository root.
3) Recent fixes had partly landed in the root copies, while the live page kept loading the older assets/ copies.
4) whatsnew.html also accumulated emergency inline CSS, creating three competing style sources.

Repair:
- assets/whatsnew-cms.js is now the only What's New renderer.
- assets/whatsnew.css is now the only What's New layout stylesheet.
- Emergency inline What's New CSS was removed from whatsnew.html.
- Root duplicate whatsnew-cms.js / whatsnew.css were deleted.
- Root duplicate wn_dummy_01.md / 03 / 04 were deleted; canonical test articles remain under content/.
- Old encoded update-note TXT in root was deleted.
- First five test records now point to images that actually exist in assets/img/.

Back Number audit:
- featured-backnumber.html -> assets/featured-backnumber.js is a clean single route.
- events-backnumber.html -> assets/events-backnumber.js is also a clean single route for VIDEO library archives.
- However assets/events-cms.js contains a separate "開催レポート" Back Number link to events-backnumber.html without a subcategory.
  That is conceptually a different archive from the video-library Back Number page and should not share the same destination.
- This audit does NOT silently redesign that archive. It is flagged for the next Back Number pass so we do not break the accepted LP.

Cleaning policy:
Only files proven to be accidental duplicates/upload debris were deleted in this pass. Older assets were not mass-deleted merely because they looked unused; that requires a dedicated reference scan to avoid breaking legacy pages.
