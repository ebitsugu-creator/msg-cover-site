「中くらいの政府」公式サイト 一式
======================================================================
2026-08-19 版　／　この中に、サイトを構成するファイルがすべて入っています。

■ パソコンで中身を見るには
  このフォルダの中の「index.html」をダブルクリックしてください。
  ブラウザが開いて、そのままサイトを見られます。
  ※パソコンで直接開いたときだけ、ヘッダー右上「お知らせ」の
    「新着」欄が空になります(ブラウザの安全機能のため)。
    サーバーに上げれば正しく表示されます。他は全て通常どおり動きます。

■ 公開(アップロード)するには
  このフォルダの中身を、そのままサーバー(Netlify)に置いてください。
  ・robots.txt と _headers に「検索よけ」の設定が入っています。
    公開準備中のあいだは検索結果に出ません。
    正式公開のときに、この2つを外す(または書き換える)だけで公開状態になります。

■ ご指示いただいた内容は、すべて反映済みです
  ・8/18 の15点 → 下の「2026-08-18(2) の更新」の項
  ・そのあとの追加4点(「別サイト」表記の廃止、関連リンク集、MIYUの入れ替え)
    → 下の「2026-08-19 の更新」の項

■ ご相談したい点が2つあります
  (1) 党公式YouTubeチャンネルのURLをお知らせください。
      関連リンク集に枠を用意してありますが、URLが分からないため
      いまは「準備中です」の表示にしてあります。
  (2) 党則 第5条の原文が「本党に党大会､党首、､総務会…」と読点が二重に
      なっていました。誤記と判断して「党首､」に整えて掲載しています。
      原文のままが良い場合はお知らせください。すぐ戻します。

「中くらいの政府」公式サイト 構成・運用メモ
======================================================================
更新: 2026-08-19

■ このサイトの作り
  ・トップページ(2026-08 白基調にリニューアル):
    自動再生の「冒頭の演出(プロローグ)」から始まり(約22秒)、
    朝もやが晴れてキービジュアル(MIYU)が立ち上がります。
    演出が終わるとキービジュアルが画面上部に縮み、同じ画面の下半分に
    「8つの入口(メニュー画面)」が現れます(スクロール不要)。
    ページの並びは 冒頭演出(→キービジュアル＋メッセージ) → 8つの入口 → フッター です。
    地は白と淡い空色、文字は紺(明朝)、差し色は金。
    ・音楽: 画面左下の「SOUND」ボタンで再生／停止できます。
      読み込み時に自動再生を試みますが、ブラウザに止められた場合は
      最初のクリック・タップで鳴り始めます。
    ・「もう一度」ボタンで冒頭の演出を先頭から見直せます。
    ・右上の「SKIP」で8つの入口まで飛べます。
    ・OSの「視差効果を減らす」設定では、演出を止めて全文を縦に並べます。
    ・トップ専用のファイル: assets/top-2026.css / assets/top-2026.js
    共通ナビ: assets/msg-nav.css / assets/msg-nav.js
  ・下層ページは普通に縦スクロールして読む作りです。
    旧サイトの「1画面=1枚のスライドを縮小表示」方式は使っていません。
  ・掲載文言は既存サイトからの引用のみです。新しい政治的な文章は
    一切書いていません（ナビの項目名などの操作用の言葉は除く）。
  ・図(政党の配置図など)は画像ではなく作図データ(SVG)なので、
    拡大しても文字がくっきりしたままです。検索・読み上げにも対応します。
  ・政党配置図は、海老原さんの修正指示(2026-08のPPTX)を正として
    白背景のさわやかな配色で作り直しています:
      - 維新・みらいは小さな政府側 / 参政〜れいわは大きな政府側(縦に分散、重ねない)
      - 自民は両側に議員がいるため大きな円(円の大小=イデオロギー分布の広さ)
      - 円はゆっくり明滅します(点滅発光)。OSの「視差効果を減らす」設定では停止
      - 企業献金の図は、自民以外の各党を「凹の字」の面でまとめ、
        「企業献金反対！」の吹き出しを添えています(構成図PPTXのイメージ)
      - 「中くらい」の帯は左右の直線のみ・中央で狭く・上下の線なし
      - 帯の中の議員が、立ち位置の近い政党と議員単位で
        支援・推薦・協働・連携・勉強会でつながる統合図にしています
      - 中央に大きな「中くらいの政府」の円は置いていません
      - 「守備範囲」という表記は図・見出しから外しました
